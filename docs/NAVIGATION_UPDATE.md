# 導覽與解析更新

使用者授權修改及上線。

- 固定上方導覽：左側「返回本回練習」採次要樣式；右側「練習首頁」採墨綠底，與匯出分開。
- 正常練習只顯示首頁導覽；錯題及匯出預覽提供兩種返回。
- 匯出預設只有一顆按鈕；展開選範圍後收合，預覽顯示更換範圍／列印或存PDF／下載。
- 匯出操作同一橫列；窄螢幕允許該列橫向捲動，不把整頁撐寬。
- A+／A− 以墨綠填色顯示剛按下的按鈕。
- 第一題完成後直接顯示四選項英文、詞性、簡短中文，以及60組各自的實用搭配／接法。
- 第二題只顯示英文參考答案，刪除重複字義說明。
- 字級、行距、全部題目／選項／答案及內容版本不變，保留作答及重練歷史。
